# 🎛️ WebUI 语音合成工作台

[← 文档索引](README.md) · [项目主页](../README.md)

装好插件后，在 AstrBot WebUI 的插件列表里找到本插件，点开它的插件页即可进入工作台。过去只能靠指令做的事，现在都能在浏览器里点：

| 视图 | 能做什么 |
| :--- | :--- |
| ◈ 工作台 | 选角色 / 感情、写文本、直接合成并试听。「分段预览」会显示句子被怎么切分、每段之后补多少停顿、哪些片段因为没有可发音字符被跳过——排查「为什么这句没读」很好用。 |
| ❀ 感情库 | 表格化管理所有角色与感情：新增、编辑、删除、复制到别的角色、整个角色改名，每行都能一键试听。 |
| ❐ 感情包 | 导出并下载 `.json`、粘贴文本导入（含三种模式与试运行）、管理服务端快照、一键恢复。 |
| ★ 收藏 | 表格化管理整个音库：浏览器里直接试听（拿的是原始音频，不转码）、改名 / 改备注 / 打标签 / 置顶、按角色 / 感情 / 会话 / 关键词筛、下载单条、拖放上传音频入库、整库导出成 `.zip` 或导入，也能把「工作台」刚试听出来的那条一键存进收藏。 |
| ⚙ 配置 | 分 11 组呈现全部 47 项配置，带说明与输入校验；需要重启才生效的项会单独标注。密钥类字段回显为掩码，不动它就不会被覆盖。 |
| ☁ 服务器 | 并发探测每台 TTS 服务器的连通性、延迟、可用角色，以及 Space 保活任务的状态。 |
| ◉ 会话 | 列出当前开了语音的会话与群，可以直接在页面上开关。 |
| ⌘ 指令表 | 全部指令与别名速查，按「开关 / 音色 / 合成 / 感情包 / 诊断」分组。 |
| ▤ 日志 | 三个子页：**合成记录**（每次合成的完整链路——LLM 原文、翻译结果、真正送进 TTS 的文本、命中的参考音频、情感来源与候选列表、分段与停顿、重试、耗时、失败原因）、**运行日志**（只收本插件的日志，按级别与分类筛，「只看问题」一档直接过滤出 WARNING 以上；**每条日志按分类带专属色条与色点，正文里的失败/成功词、引号内文本、标识符与路径、数字都会分色高亮**，可用卡片上的「着色」开关关掉）、**情感统计**（按「角色 · 情感」聚合并按失败率倒序，回答「哪些情感不好」）。支持关键词搜索、5 秒自动刷新、一屏复制、按当前筛选导出 `.txt`、清空缓冲。 |
| ⓘ 关于 | 版本、数据目录、感情统计与合成计数，以及按分区列出的全部 WebUI 接口清单。 |

**主题**：月夜（默认，深色）· 樱色（浅色）· 黄昏（深色）· 苍海（深色）· 薄雪（浅色）· 绯夜（深色），外加「舒适 / 紧凑」两种信息密度。选择保存在插件自己的 KV 存储里（不是浏览器 localStorage），所以换浏览器、换设备都是同一套外观。

> 工作台依赖 AstrBot 的插件页与 `register_web_api` 能力（在 AstrBot v4.25 上验证）。若你的 AstrBot 版本不提供这些能力，插件会在日志里提示并自动跳过工作台注册，其余功能照常工作。
